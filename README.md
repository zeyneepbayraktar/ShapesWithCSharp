# ShapesWithCSharp
Object-oriented shape hierarchy in C# demonstrating abstract classes, inheritance, and polymorphism.
Class Structure
Shape (abstract)
├── TwoDimensionalShape (abstract)
│   ├── Circle
│   └── Square
└── ThreeDimensionalShape (abstract)
    ├── Sphere
    └── Cube
Concepts Used

Abstract classes
Inheritance
Polymorphism
Method overriding

bashdotnet run
